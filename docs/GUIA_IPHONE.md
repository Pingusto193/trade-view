# Guia: usar o Radar no iPhone

O Radar é um site que vira "app" quando você o adiciona à Tela de Início (PWA). Não precisa da App Store.

## 1. Instalar

1. Abra o endereço do seu Radar no **Safari** (precisa ser o Safari e ter **https://**).
2. Toque em **Compartilhar** (o quadrado com a seta para cima).
3. Toque em **Adicionar à Tela de Início** e em **Adicionar**.
4. Abra o Radar **pelo ícone** que apareceu. Daqui em diante, use sempre o ícone.

Dentro do app, **Mais › Instalar o app** mostra os mesmos passos com imagens.

## 2. Notificações dos alertas

O iPhone só entrega notificações de apps instalados na Tela de Início, a partir do **iOS 16.4** (regra da
Apple). O passo a passo está no `GUIA_NOTIFICACOES.md`, seção 1.

## 3. Dicas de uso no celular

- A barra de baixo tem **Gráfico, Treino, Listas, Alertas e Mais**. No modo **Real**, o lugar do Treino
  passa a ser o **Diário**.
- No gráfico, toque e segure para ver os valores de um candle; use dois dedos para aproximar.
- No **Replay**, o botão grande "Próximo candle" avança um candle por toque.
- Tudo fica no servidor: o que você faz no iPhone aparece no PC (e vice-versa).

## Problemas comuns

| Problema | O que fazer |
| --- | --- |
| Não aparece "Adicionar à Tela de Início" | Use o Safari (não o Chrome do iPhone) e role o menu Compartilhar para baixo. |
| O app pede login toda vez | Abra pelo ícone, não por um link do Safari: são "lugares" diferentes para o iPhone. |
| Notificação não chega | Veja **Ajustes › Notificações › Radar** e o modo Foco. Repita "Ativar notificações". |
| Ficou com uma versão velha | Feche o app (deslize para cima) e abra de novo: aparece "Nova versão disponível". |
